# โครงสร้างของลิพโพจิทรี Orange

## โฟลเดอร์หลัก

### `.github`
- บรรจุไฟล์การตั้งค่า GitHub Actions workflows
- สำหรับการอัตโนมัติของขั้นตอนการพัฒนา (CI/CD)

### `src`
- ซอร์สโค้ดหลักของแอปพลิเคชัน
- ส่วนหน้า (Frontend) ของโปรเจค

### `src-tauri`
- ซอร์สโค้ด Tauri backend
- ส่วนหลัง (Backend) ที่ใช้ Rust
- สำหรับการสร้างแอปพลิเคชันเดสก์ทอป

### `doc`
- ไฟล์เอกสารประกอบ
- คำแนะนำและข้อมูล��พิ่มเติม

### `public`
- ไฟล์สาธารณะที่ให้บริการต่อไป
- สินทรัพย์แบบคงที่ (static assets)

### `screenshot`
- ภาพหน้าจอของแอปพลิเคชัน
- ใช้สำหรับเอกสารและการโฆษณา

## ไฟล์สำคัญ

### `package.json`
- ข้อมูลเมตาของโปรเจค Node.js
- รายการ dependencies และ scripts

### `yarn.lock`
- ไฟล์ล็อกของ Yarn package manager
- รับประกันเวอร์ชันที่แน่นอนของ dependencies

### `.gitignore`
- รายการไฟล์/โฟลเดอร์ที่ไม่ติดตามด้วย Git

### `.yarnrc.yml`
- ไฟล์การตั้งค่า Yarn

### `LICENSE`
- ใบอนุญาตของโปรเจค

### `README.md`
- เอกสารหลักเป็นภาษาอังกฤษ
- ข้อมูลทั่วไปและวิธีการใช้งาน

### `README_cn.md`
- เอกสารหลักเป็นภาษาจีน

### `app-icon.png`
- ไอคอนของแอปพลิเคชัน
- ใช้ในหน้าต่างและการเปิดตัว

## สรุป

โปรเจค Orange เป็นแอปพลิเคชันเดสก์ทอปที่สร้างขึ้นด้วย:
- **Frontend**: Vue.js หรือ Framework อื่น (ใน src)
- **Backend**: Rust + Tauri (ใน src-tauri)
- **Package Manager**: Yarn
- **Documentation**: หลายภาษา (อังกฤษ, จีน, และปัจจุบัน ไทย)
